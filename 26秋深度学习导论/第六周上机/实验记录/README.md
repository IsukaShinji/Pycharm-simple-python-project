# 第六周选做实验记录

本目录保存 `emb_size` 选做实验的原始运行记录，方便核对报告中的数据。主提交代码仍是上级目录中的 `task2_2.py`，其默认特征维度为 128。

- `task2_2_emb.py`：临时参数化运行脚本，通过命令行参数指定 `emb_size`，用于补充 64 维对比实验。
- `emb_size_64_raw.log`：64 维、5 个 epoch 的原始终端输出，包含每轮训练损失和测试准确率。

64 维实验的运行方式：

```text
python task2_2_emb.py 64
```

128 维基线的模型和超参数与 `task2_2.py` 的默认配置一致，运行时使用了等价的临时脚本。它是一次单次运行，未显式固定随机种子，原始终端输出未保留；报告中的 128 维逐轮数值来自这次运行。64 维实验同样没有显式固定随机种子，但保留了原始日志。两组实验的数据集、预处理、ResNet18 图像编码器、LSTM 文本编码器、Adam 学习率、batch size 和训练轮数相同。补充脚本把 `DataLoader` 的 worker 数设为 4，仅用于减少等待时间，不改变模型和训练超参数。
