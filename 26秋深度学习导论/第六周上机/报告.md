## 一、任务一：卷积层的手动求导

### 1.1 手动求导原理

本实验使用 `padding=0`、无偏置、无激活函数的单通道卷积层，输入 `A` 的形状为 `(1, 32, 32)`，卷积核 `W` 的形状为 `(1, 1, 3, 3)`，卷积输出为 `Z = W * A`。目标函数取

\[
f(Z)=\sum_{i,j} Z_{i,j}.
\]

由于求和函数对每个输出元素的导数都是 1，因此反向传播时传入卷积层的梯度张量全为 1，即

\[
\frac{\partial f}{\partial Z_{i,j}}=1.
\]

对于卷积核位置 `(p, q)`，其梯度等于该卷积核在全部滑动位置上对应的输入元素之和：

\[
\frac{\partial f}{\partial W_{p,q}}
=\sum_{i=0}^{29}\sum_{j=0}^{29} A_{i+p,j+q},
\qquad p,q\in\{0,1,2\}.
\]

代码中使用 `A_2d[p:p+30, q:q+30].sum()` 实现该求和，其中 `A_2d` 是去掉 batch 维后的 `(32, 32)` 输入。卷积核共 9 个位置，因此用两层循环分别计算 `p`、`q`。

### 1.2 运行结果

PyTorch 自动微分得到的梯度为：

```text
[[[-5.4888, -11.7105, -20.3536],
  [-14.1905, -18.2850, -27.4373],
  [-12.8152, -19.3680, -25.0430]]]
```

手动计算得到的结果与自动微分完全一致，程序输出的最大绝对误差为：

```text
Max abs difference: 5.7220458984375e-06
```

该误差量级来自浮点数累加顺序的差异，而不是梯度公式错误。任务一验证通过。

## 二、任务二：传统图像分类与简化 CLIP 的对比

### 2.1 两种方法的输入输出差异

**传统图像分类：** 输入是一张图像，模型通过 ResNet18 提取特征，再经过一个线性分类层输出 10 个类别的 logits。训练时使用图像标签和交叉熵损失，模型学习的是从图像到固定类别标签的映射。推理阶段只能输出训练时定义的类别。

**简化 CLIP：** 输入是图像和文本描述。本实验根据标签生成 `a photo of [label]`，再将其分词并转换为 token id。图像编码器和文本编码器分别输出 128 维特征，经过 L2 归一化后计算图像与文本的余弦相似度，并用对称对比损失训练。推理阶段不再依赖单独的线性分类头，而是把图像特征与 10 个文本描述的特征进行匹配，取相似度最高的文本对应的类别。

两者的关键区别如下：

| 对比项 | 传统图像分类 | 简化 CLIP |
| --- | --- | --- |
| 图像输入 | 图像 | 图像 |
| 文本输入 | 无 | `a photo of [label]` 的 token id |
| 输出 | 10 类 logits | 图像与文本特征的相似度 |
| 监督信号 | 图像标签 + 交叉熵 | 同一 batch 内图像-文本正负样本对比 |
| 分类方式 | 固定分类头 | 图像与文本描述匹配 |
| 类别扩展 | 需要重新训练或修改分类头 | 理论上替换文本描述即可扩展 |

### 2.2 训练逻辑

传统分类任务每个 batch 执行：清空梯度、ResNet 前向传播、交叉熵损失、反向传播和 Adam 更新。CLIP 任务每个 batch 同时输入图像和对应标签生成的文本 token，分别编码后计算对称对比损失：

\[
\mathcal{L}=\frac{1}{2}\left(\mathcal{L}_{i\to t}+\mathcal{L}_{t\to i}\right),
\]

其中图像到文本和文本到图像两个方向都使用交叉熵，正样本为同一 batch 中相同下标对应的图文特征，其他样本作为负样本。这样可以使匹配的图像和文本在特征空间中靠近，同时拉开不匹配样本的距离。

### 2.3 实验设置

- 数据集：FashionMNIST，训练集 60000 张，测试集 10000 张，10 个类别。
- 图像预处理：单通道转三通道，缩放到 `224×224`，使用 ImageNet 均值和标准差归一化。
- 图像编码器：ImageNet 预训练 ResNet18，输出 128 维特征。
- 文本编码器：词嵌入维度 128、LSTM 隐藏维度 256，输出 128 维特征。
- 传统分类器：ResNet 特征后接 `Linear(128, 10)`。
- CLIP 损失：温度系数 `temperature=0.07` 的对称对比损失。
- 优化器：Adam，学习率 `0.001`。
- batch size：32。
- 训练轮数：5 个 epoch。
- 实验环境：Windows，PyTorch 2.9.0（XPU 版），使用 Intel Arc GPU。

## 三、实验结果

### 3.1 传统图像分类

| Epoch | 训练损失（交叉熵） | 测试准确率 |
| --- | ---: | ---: |
| 1 | 0.3472 | 90.60% |
| 2 | 0.2340 | 92.09% |
| 3 | 0.1921 | 93.65% |
| 4 | 0.1627 | 93.21% |
| 5 | 0.1321 | 93.69% |

### 3.2 简化 CLIP

| Epoch | 训练损失（对比损失） | 测试准确率 |
| --- | ---: | ---: |
| 1 | 1.6169 | 90.72% |
| 2 | 1.5210 | 91.72% |
| 3 | 1.4826 | 93.03% |
| 4 | 1.4571 | 93.15% |
| 5 | 1.4320 | 93.04% |

说明：128 维基线为单次运行，未显式固定随机种子，原始终端输出未保留；上表记录的是当次运行得到的逐轮结果。

### 3.3 结果对比与分析

传统分类的交叉熵从 `0.3472` 降到 `0.1321`，测试准确率从 `90.60%` 升到 `93.69%`，第 4 轮有回落。CLIP 的对比损失从 `1.6169` 降到 `1.4320`，准确率在 `93%` 左右，第一轮已经比较高，后面提升幅度较小。两种 loss 含义不同，这里只比较各自的逐轮变化和最终准确率。最终传统分类为 `93.69%`，简化 CLIP 为 `93.04%`。

## 四、选做实验：不同特征维度的实测对比

选择比较编码器输出维度 `emb_size` 对简化 CLIP 的影响。以 `emb_size=64` 和 `emb_size=128` 两组进行实际训练；除特征维度外，数据集、图像预处理、ResNet18 图像编码器、LSTM 文本编码器、Adam 学习率 `0.001`、batch size 32 和 5 个 epoch 均保持一致。64 维运行的原始日志和补充脚本放在 `实验记录/` 目录，报告里的数据可以直接对照日志。128 维基线为单次运行，未显式固定随机种子，原始终端输出未保留。

### 4.1 逐轮结果

### 4.2 最终结果对比

| 特征维度 | 最终训练损失 | 最终测试准确率 |
| --- | ---: | ---: |
| 64 | 1.4388 | 93.37% |
| 128 | 1.4320 | 93.04% |

### 4.3 结果分析

64 维最终 loss 为 `1.4388`、准确率为 `93.37%`；128 维最终 loss 为 `1.4320`、准确率为 `93.04%`。两组都只跑了一次，且未固定随机种子，0.33 个百分点不足以判断 64 维和 128 维谁更优。256 维未运行，因此不作比较。

## 五、结论

任务一的手动梯度与 PyTorch 自动微分结果一致，最大误差为 `5.72e-06`。任务二跑通了传统分类和简化 CLIP 两套流程，最终准确率分别为 `93.69%` 和 `93.04%`；64 维与 128 维的选做对比也没有拉开明显差距。两种方法都能完成 FashionMNIST 分类，主要区别在监督信号和分类方式。
