## 一、代码及数据说明

先核对数据文件：`data_processed.csv` 去掉表头共 1460 行、239 列，前 237 列为特征，倒数第二列 `SalePrice` 是房价（连续值，回归标签），最后一列 `PriceClass` 是三分类标签，取值 0/1/2，分别代表“相对较低 / 标准值 / 相对较高”。全表没有缺失值，三类样本数分别是 439、732、289。

特征列基本都做过标准化（均值 0、方差 1 附近，一部分是 0/1 哑变量），而回归标签 `SalePrice` 仍是原始量级（3.49 ~ 75.5），没有标准化，这一点在调学习率时要注意。

`code_week2.py` 中各函数的作用与说明一致：`train_linear_regression` 和 `train_softmax` 做全量梯度下降，`compute_gradients_regression` 和 `compute_gradients_softmax` 计算含 L2 正则项的梯度。

## 二、上机任务 1：损失函数

### 1. rmse()

均方误差 MSE = (1/n)·Σᵢ(yᵢ − ŷᵢ)²，RMSE 就是它开根号：

```python
return np.sqrt(np.mean((y_true - y_pred) ** 2))
```

开根号是为了把量纲拉回和房价一致，方便直接判断误差有多大。

### 2. softmax() 与思考

实现是“减去每行最大值再求指数、按行归一化”：

```python
z_max = np.max(z, axis=1, keepdims=True)
exp_z = np.exp(z - z_max)
return exp_z / np.sum(exp_z, axis=1, keepdims=True)
```

**按定义直接实现会遇到什么问题**

- 上溢：如果 z 里出现较大的正数（比如 1000），`np.exp` 会溢出成 inf，分子分母都是 inf，相除得到 nan。用 float64 时大约 z > 709 就开始出问题。
- 下溢与除零：如果整行都是很负的数，每个 exp 都下溢成 0，分母为 0，直接得到 0/0；即使分母不严格为 0，有效数字也已经丢光。
- 与交叉熵连用时的精度损失：先算概率再取对数，当概率很小时误差会被放大。理论上交叉熵可以直接用 log-sum-exp 写成 log p_k = z_k − log Σⱼ exp(zⱼ)，绕开“先 exp 再 log”这一步。
- 维度问题：`np.max(z, axis=1)` 是按批量输入 (n_samples, n_classes) 设计的，如果传进来的是单个一维样本，axis=1 越界会直接报错，需要先判断 z.ndim == 1 再按整体最大值处理。
- 另外，softmax 对输入整体加同一个常数结果不变，说明 logits 存在冗余（权重可以整体平移），这是 softmax 回归的固有性质。

**鲁棒写法**

关键是利用 softmax 的平移不变性：softmax(z) = softmax(z − c)，取 c 为每行的最大值。这样最大分量变成 exp(0) = 1，分母至少为 1，既不会上溢成 inf，也不会出现 0/0；而且它与原始定义在数学上完全等价，不改变结果。

在交叉熵里再配合 log-sum-exp，或者对概率做下限截断（代码里用 `np.clip(y_prob, 1e-15, 1.0)`），可以避免 log(0)。本次输入是标准化特征、logits 数值不大，不加保护也不会出问题，但作为通用函数加上更稳妥。

### 3. cross_entropy_loss()

按 L = −(1/n)·Σᵢ log pᵢ,ᵧᵢ 实现：用花式索引 `y_prob[np.arange(n_samples), y_true]` 取出每个样本真实类别对应的概率，取负对数再求平均。取对数之前把概率截断到 [1e-15, 1]，避免某个样本概率为 0 时 log(0) = −inf 把整批损失污染掉。

## 三、上机任务 2：梯度与全量梯度下降

### 1. 梯度推导

**（1）线性回归（含 L2 正则）**

记误差 e = Xw + b − y，损失取

L(w, b) = (1/2n)·Σᵢ(xᵢᵀw + b − yᵢ)² + (λ/2)·‖w‖²

对 w、b 求偏导：

∂L/∂w = (1/n)·Xᵀ(Xw + b − y) + λw

∂L/∂b = (1/n)·Σᵢ(xᵢᵀw + b − yᵢ)

对应代码里 `dw = (1 / n_samples) * X.T.dot(error) + reg_lambda * w` 与 `db = (1 / n_samples) * np.sum(error)`。正则项约定为 (λ/2)‖w‖²，求导后正好是 λw，与代码一致，并且不对偏置 b 做正则。

关于损失函数形式：任务说明里写的是“RMSE 损失的梯度”，这里按均方误差（RMSE 的平方）推导。因为 RMSE = sqrt(MSE)，有 ∂RMSE/∂w = (∂MSE/∂w) / (2·RMSE)，只差一个正的比例系数，下降方向完全一致；而 MSE 处处可导、形式更简单，实践中通常也是按 MSE 更新参数、用 RMSE 汇报误差。

**（2）Softmax + 交叉熵（含 L2 正则）**

前向：z = XW + b，p = softmax(z)

损失：L = −(1/n)·Σᵢ log pᵢ,ᵧᵢ + (λ/2)·‖W‖²

先对单个样本的 logits 求导。由 softmax 定义得 ∂p_k/∂z_j = p_k(δ_{kj} − p_j)，代入交叉熵化简后得到很干净的结果：

∂Lᵢ/∂z_k = p_k − 1{k = yᵢ}

写成向量形式就是 ∂Lᵢ/∂zᵢ = pᵢ − e_{yᵢ}（e 为 one-hot 向量），即“预测概率 − 真实标签”。再用链式法则对 W、b 求导：

∂L/∂W = (1/n)·Xᵀ(P − Y) + λW

∂L/∂b = (1/n)·Σᵢ(pᵢ − eᵢ)

代码里 `dz = probs.copy(); dz[np.arange(n_samples), y] -= 1` 就是在构造每行的 P − Y，后两行 `X.T.dot(dz) / n` 和 `np.sum(dz, axis=0) / n` 分别对应上面两式；除以 n_samples 是因为损失对样本取了平均。

（顺带做了一次核对：用数值微分 (L(θ+ε) − L(θ−ε)) / 2ε 与解析梯度对比，两者相差约 1e-9 量级，说明推导和实现没有写错。）

### 2. 全量梯度下降

两个训练函数每次迭代都用全部 n 个训练样本计算梯度，而不是随机取一个样本或一小批：

```python
for i in range(num_iterations):
    dw, db = compute_gradients_regression(X_train, y_train, w, b, reg_lambda)
    w -= learning_rate * dw
    b -= learning_rate * db
```

分类那边同理，只是梯度函数多返回一个 loss 方便观察。

数据划分用 `train_test_split`，test_size=0.25、random_state=42，得到 1095 条训练数据和 365 条测试数据。全量梯度下降单步代价是 O(n·d)（分类再乘类别数 K），好处是梯度方向准确、损失稳定下降，代价是单步开销大、收敛慢。

### 3. 超参数实验

实验设置：

- 学习率：回归取 1e-4 / 5e-4 / 1e-3 / 2e-3，分类取 1e-3 / 5e-3 / 1e-2 / 5e-2
- 迭代周期：对比实验统一跑 2000 步，主程序跑 10000 步
- 每个配置都记录训练过程中的 RMSE、交叉熵、准确率并画在同一张图里（`week2_experiments.png`，三栏），横轴就是迭代次数，所以同一个配置在 500 / 1000 / 2000 步时的收敛情况可以直接从曲线上读出来

| 回归（RMSE） | 5e-4 | 3.4312 | 3.4170 |

| 迭代次数 | 回归训练 RMSE | 分类训练损失 |

**结果分析**

1. 学习率的影响：四组取值下曲线都是平滑下降，没有出现震荡或发散，说明都在稳定范围内。学习率越大，前期下降越快、同样 2000 步时误差越低（回归 2e-3 最好，分类 5e-2 最好）。1e-4 那一组明显偏慢，2000 步只降到 3.87，需要更多迭代才能补回来。
2. 但“稳定”是有上限的，这一点从曲线看不出、需要单独试：把回归的学习率放大到 1e-2 立刻发散，第 100 步 RMSE 就冲到 3.5e18，1000 步变成 inf；2e-2、5e-2 更早溢出成 inf/nan。实测 5e-3 仍然稳定（2000 步 RMSE 2.964），所以回归的稳定上界在 5e-3 ~ 1e-2 之间。

| 回归学习率 | 2000 步后的训练 RMSE |
| --- | --- |
| 2e-3 | 3.119 |
| 5e-3 | 2.964 |
| 1e-2 | 发散（第 100 步 3.5e18，1000 步 inf） |
| 2e-2 | 发散（第 100 步 1.7e61，500 步 inf） |
| 5e-2 | 发散（第 100 步 1.3e128，500 步 nan） |

3. 迭代周期的影响：收益递减。回归前 1000 步 RMSE 从 19.77 降到 3.43，之后 9000 步只又降到 2.97；到 10000 步曲线仍在缓慢下降，还没有完全收敛。所以迭代次数不是越多越好，要看损失曲线是否已经平掉。
4. 只看训练指标会误判：分类跑 2000 步时，lr=1e-2 的训练准确率 0.8977 高于 lr=5e-3 的 0.8776，但测试准确率反而更低（0.8274 对 0.8329），说明前者已经开始过拟合。选超参数要看验证/测试表现，不能只盯训练集。
5. 两个任务对步长的敏感度不同：回归有 237 维特征、其中不少是近共线的哑变量，XᵀX 的最大特征值偏大，稳定步长上限只有 5e-3 量级；分类的 logits 由 3 组权重决定，同样的数据下可以用到 5e-2 仍然稳定。这也是两组实验的学习率范围要分开取的原因。
